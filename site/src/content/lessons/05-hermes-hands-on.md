# 第 5 堂：Hermes Agent 實作

## 基本資訊

- **時長**：50 分鐘
- **型態**：Hands-on Lab（學員跟著操作）
- **對應學習目標**：5.1 完成 Hermes 安裝與設定、5.2 執行第一個 Agent 任務、5.3 啟用並使用多種工具、5.4 觀察自學習迴圈的運作

---

## 教學流程

### 第一階段：環境安裝（10 min）

**目標**：每位學員都成功安裝 Hermes 並完成初始設定。

**步驟 1：開啟終端機（1 min）**

- macOS：開啟「終端機」app（Spotlight 搜尋 Terminal）
- Windows：開啟 PowerShell（建議使用 WSL2，若無則用 PowerShell 亦可）
- 確認終端機可用：輸入 `echo hello`，應該看到 `hello` 回應

**步驟 2：執行安裝腳本（3 min）**

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

**操作說明**：

- 這行指令做三件事：下載安裝腳本、執行安裝、把 `hermes` 指令加到系統路徑
- 安裝過程中會看到進度條，正常情況 1-2 分鐘完成
- 如果看到權限相關錯誤，macOS 可能需要在「系統偏好設定 > 安全性與隱私」中允許執行

**常見問題處理**：

| 問題 | 解法 |
|------|------|
| `curl: command not found` | 先安裝 curl：macOS 用 `brew install curl`，Windows 下載安裝包 |
| 權限被拒 | 加 `sudo`：`sudo curl -fsSL ... \| sudo bash` |
| 網路逾時 | 確認是否在公司防火牆後，可能需要切換到手机熱點 |
| `hermes: command not found`（安裝後） | 關閉終端機重新開啟，或執行 `source ~/.bashrc`（或 `~/.zshrc`） |

**步驟 3：執行初始設定（4 min）**

```bash
hermes setup
```

**設定過程會依序詢問**：

1. **選擇模型供應商**：選 OpenAI 或 Anthropic（依學員持有的 API Key 而定）
2. **輸入 API Key**：貼上你的 API Key（畫面不會顯示字元，這是正常的）
3. **選擇預設沙箱**：建議選 Docker（若未安裝 Docker 則選 local）
4. **確認設定**：輸入 `y` 確認

**注意事項**：

- API Key 可以到 platform.openai.com 或 console.anthropic.com 申請
- API Key 是你的個人憑證，**不要分享給他人**，也不要貼到聊天群組或文件中
- 如果不小心洩漏了 API Key，立即到平台上重新產生一組新的
- 安裝完成後會看到「Hermes is ready!」的訊息

**隱私保護提醒（實作前必讀）**：

接下來我們要開始跟 AI 模型對話了。請務必遵守以下規則：

- **不要輸入真實姓名**：用「小明」「小華」等化名代替
- **不要輸入個案內容**：用虛構的範例資料來練習
- **不要輸入任何密碼或 API Key 到對話中**：剛才輸入的 API Key 是設定階段，不算對話內容
- 如果練習中需要文件資料，請使用課程提供的範例檔案，不要使用工作中的真實文件
- 確認安裝完成後再繼續後續步驟

**快速驗證**：

```bash
hermes --version
hermes config show
```

應能看到版本號和目前的設定摘要。

### 第二階段：第一個任務 — 讓 Hermes 幫你整理文件（10 min）

學員親身體驗 Agent 從接收指令到完成任務的完整流程。

**步驟 1：啟動互動模式（2 min）**

```bash
hermes chat
```

進入後會看到 Hermes 的提示符號，表示 Agent 已就緒。

**步驟 2：建立測試用檔案（2 min）**

準備一些測試素材。在另一個終端機視窗執行：

```bash
mkdir -p ~/hermes-workshop
cat > ~/hermes-workshop/notes.txt << 'EOF'
週一：課輔班開課，國小三年級組 12 位學童全勤，數學單元「分數入門」進度正常
週二：教材修訂會議，決議將高年級閱讀理解教材補充 3 篇科普文章
週三：個案研討會，社工師報告小明的家庭訪視狀況，需安排特教老師介入
週四：家長座談會，8 位家長出席，多數關心暑假課輔續辦規劃
週五：課後活動日，美術老師帶領創意手作，需在本週日前完成活動成果拍照與歸檔
EOF
```

**步驟 3：下達整理任務（6 min）**

回到 Hermes 對話視窗，輸入：

```
請讀取 ~/hermes-workshop/notes.txt 這個檔案，整理這週的課輔中心工作紀錄，把內容整理成：
1. 一份條列式的「本週課輔中心工作摘要」，按重要性排序
2. 標記出需要後續跟進的事項（附上截止日期）
3. 把結果存成 ~/hermes-workshop/summary.md
```

**操作說明**：

- 觀察 Hermes 的行為：它會先讀取檔案、分析內容、整理格式、再寫入新檔案
- 這就是「Model 規劃 → Tools 執行」的流程在實際運作
- 注意看終端機上的輸出，會顯示 Agent 正在使用哪些工具

**完成後你可以驗證**：

檢查 `summary.md` 的內容，確認是否包含：
- 按重要性排序的工作摘要
- 標記了需要後續跟進的事項（附上截止日期）
- 格式清晰、可讀性高

**驗證**：

```bash
cat ~/hermes-workshop/summary.md
```

### 第三階段：工具啟用與觀察 — 網頁搜尋、檔案操作、排程（15 min）

**步驟 1：查看可用工具（2 min）**

```bash
hermes tools list
```

會列出所有已安裝和可啟用的工具。說明：

- 已啟用（enabled）：可直接使用
- 可啟用（available）：需要額外設定才能使用
- 每個工具旁邊會標示風險等級（低/中/高）

**步驟 2：啟用網頁搜尋工具（4 min）**

```bash
hermes tools enable web_search
```

回到 Hermes 對話中測試：

```
幫我搜尋「偏鄉教育數位化工具 2026」，找出 3 個重點，整理成簡短摘要。
```

**觀察重點**：

- Hermes 會呼叫網頁搜尋工具、閱讀搜尋結果、整理重點
- 仔細看 Agent 的輸出：它選擇了什麼工具？搜尋了幾次？閱讀了哪些結果？
- 這就是第 4 堂學到的「工具風險光譜」在實際運作——搜尋是中風險工具，Agent 使用時應該有明確目的

**步驟 3：啟用排程工具（4 min）**

```bash
hermes tools enable scheduler
```

測試排程功能：

```
設定一個排程任務：每天早上 9 點，讀取 ~/hermes-workshop/notes.txt，
如果檔案有更新，就自動產生新的課輔中心工作摘要覆蓋 ~/hermes-workshop/summary.md。
```

**說明**：

- 排程工具讓 Agent 從「被動等人下指令」變成「主動定期執行」
- 課輔中心的日常自動化就是這樣開始的 — 把重複性行政工作交給 Agent

**步驟 4：觀察 Agent 的工具選擇（5 min）**

現在刻意用一個「模糊的指令」測試 Agent：

```
整理一下課輔的東西。
```

**觀察重點**：

- Agent 會怎麼理解「課輔的東西」？它會找什麼檔案？
- 它選擇了哪些工具？順序合理嗎？
- 對比步驟 2 中你給的精準指令，Agent 的表現有什麼差異？

**討論**：

- 這就是第 4 堂學到的「精準提問」的重要性——指令越模糊，Agent 越容易選錯工具或走偏
- 好的使用者不是等 Agent 出錯再修正，而是在一開始就給出清楚的指令

### 第四階段：Context Awareness 實作體驗（10 min）

**學習重點**

第 4 堂課學到了 Context 如何影響 Agent 的表現，現在透過實驗親身體驗。

**實驗一：Context 長度對 Agent 表現的影響（4 min）**

在同一個對話中連續下達多個任務，觀察 Agent 的表現變化：

```
第一步（初始指令，加入限制條件）：
「請幫我整理課輔中心的工作紀錄。
 重要規則：所有學童姓名必須用編號取代，不能出現真實姓名。
 讀取 ~/hermes-workshop/notes.txt，整理成摘要，存到 ~/hermes-workshop/test-summary-1.md」

第二步（等待完成後，在同一對話中繼續）：
「請搜尋『偏鄉教育 2026』，找出 2 個重點」

第三步（繼續在同一對話中）：
「請再幫我整理一次課輔中心的工作紀錄，讀取同一個檔案，存到 ~/hermes-workshop/test-summary-2.md」
```

**觀察重點**：

- 第一次整理時，Agent 有沒有遵守「用編號取代姓名」的限制？
- 經過第二個任務後，第三次整理時，Agent 還記得「用編號取代姓名」的規則嗎？
- 如果 Agent 忘記了，這就是 Context Window 被新內容佔據、舊指示被「擠掉」的實際案例

**實驗二：精準 vs 模糊的 Prompt 對比（4 min）**

開一個新的對話，分別用兩種方式下達同一個任務：

**模糊版**：
```
整理課輔資料
```

**精準版**：
```
請讀取 ~/hermes-workshop/notes.txt，
整理成一份「本週課輔中心工作摘要」：
1. 按重要性排序
2. 標記需要後續跟進的事項
3. 學童姓名用編號取代
4. 輸出為 Markdown 格式
5. 存到 ~/hermes-workshop/test-summary-3.md
```

**觀察重點**：

- 模糊版：Agent 花了多少步驟？有沒有猜錯你要什麼？結果品質如何？
- 精準版：Agent 的執行是否更精簡？結果是否更符合你的期待？
- 討論：精準版多了哪些資訊？這些資訊分別幫 Agent 省去了什麼「猜測」？

**自學習迴圈簡介（2 min）**

Hermes 有一個特色功能：Agent 會從成功經驗中「學到技能」。例如第一次整理課輔週報花 5 步，第二次遇到類似任務可能只需 2 步。查看技能記錄：

```bash
hermes skills list
```

這不是模型在「重新訓練」，而是把成功的工作流程存為模板，下次可以更快完成。

### 第五階段：總結與預告（5 min）

**總結重點**

1. Hermes 的安裝只需要一條指令加上互動式設定
2. Agent 的工作流程：接收任務 → 規劃步驟 → 呼叫工具 → 產出結果
3. 精準的指令讓 Agent 更有效率——一次說清楚目標、步驟、格式和限制
4. Context 長度會影響 Agent 的表現，對話太長時 Agent 可能遺忘早期的指示
5. 當 Agent 開始遺忘或偏離時，開新對話是最有效的解法

**預告下一堂**

- 下一堂（第 6 堂）是辦公室場景工作坊
- 學員會分組，選擇一個博幼基金會的真實業務場景，用今天學到的 Hermes 技能來解決
- 先想一想：在課輔中心或行政工作中，有哪些重複性任務適合交給 Agent？
- 建議今晚回家再多練習一下 Hermes，越熟悉操作，下堂課越順利

## 關鍵概念

| 概念 | 一句話解釋 |
|------|-----------|
| Hermes 安裝 | 一行指令安裝 + 互動式設定，幾分鐘即可開始使用 |
| 互動模式 | `hermes chat` 進入對話式操作，像跟一個助理聊天 |
| 工具啟用 | `hermes tools enable <工具名>` 擴展 Agent 能力 |
| 工具風險等級 | 每個工具有低/中/高的風險分級，高風險需確認 |
| 精準提問 | 一次說清楚目標、步驟、格式和限制，Agent 表現更好 |
| Context 影響 | 對話越長，Agent 越容易遺忘早期指示；適時開新對話 |
| 自學習迴圈 | Agent 記錄成功經驗，下次遇到類似任務更高效 |
| 技能累積 | 學到的能力以模板形式保存，可查看和重複使用 |

## 延伸活動（若有餘裕時間）

### 挑戰：Prompt 改寫擂台

給自己 5 分鐘，挑一個你在工作中常做的重複性任務，分別用「模糊版」和「精準版」兩種方式讓 Hermes 執行。比較兩次的結果差異：

- Agent 的步驟數量
- 結果的準確度和完整度
- 是否需要修正或重新下指令

體驗一下：好的指令能省下多少來回溝通的時間。

### 探索：Context 邊界測試

嘗試在一個對話中連續下達 5 個以上的不同任務，觀察：

- Agent 在第幾個任務開始遺忘第一個任務的限制條件？
- 開新對話後重新下達同樣的任務，表現有什麼差異？

這個實驗幫助你建立對「何時該開新對話」的直覺。
