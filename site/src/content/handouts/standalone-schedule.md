# Hermes Agent 全天實作工作坊 — 獨立課表

## 工作坊定位

這是一門以 Hands-on 實作為主的全天工作坊。上午先建立共通操作能力，下午進入博幼基金會場景實戰，最後以分組成果展示收尾。你將在一天內完成安裝、操作、流程設計、原型優化與成果展示。

## 基本資訊

- **課程名稱**：Hermes Agent 全天實作工作坊
- **教學時間**：6 小時
- **活動總時長**：約 7 小時 50 分鐘（含休息與午餐）
- **進行方式**：全程實作，活動採分組進行
- **適合對象**：已具備基礎 AI Agent 概念，想進一步做實作落地的在職人士
- **設備需求**：學員自備筆電、可連網環境、終端機與 API Key

## 學員將完成的成果

- 完成 Hermes Agent 安裝與基本設定
- 執行第一個實作任務
- 啟用並使用搜尋、檔案、排程等工具
- 建立一個可重複執行的自動化工作流
- 在真實博幼基金會場景中完成一版 Agent 原型
- 與小組共同完成展示與整合挑戰
