# 教材製作 Prompt 模板

這份模板給教材幕僚、教學組長或課輔老師使用。先讓 Agent 做出可審的第一版，不求它一次寫完整份教材。

---

## 使用前先確認

- 已去識別化，不含真實姓名或個案細節
- 已說清楚單元、年級與教學目標
- 已整理出至少 2–3 個常見錯誤
- 已決定這一輪要先產出什麼，不要一次要求太多

---

## 建議輸入欄位

請先把以下資訊補齊：

- **年級／科目**：
- **單元名稱**：
- **教學目標**：
- **先備知識**：
- **學童常見錯誤**：
- **目前教材問題**：
- **這一輪想先產出的內容**：
- **哪些地方一定要人工審查**：

---

## Prompt 模板

```text
你現在要協助處理一份博幼基金會課輔教材的第一版草稿。

請根據我提供的資訊，先做出可供人審查的版本。
如果資料不足，請標記「待確認」，不要自己補出沒有依據的內容。

資料如下：
- 年級／科目：{{年級／科目}}
- 單元名稱：{{單元名稱}}
- 教學目標：{{教學目標}}
- 先備知識：{{先備知識}}
- 學童常見錯誤：{{學童常見錯誤}}
- 目前教材問題：{{目前教材問題}}

這一輪請先產出：
1. 先備知識提醒
2. 基礎版練習 {{數量}} 題
3. 標準版練習 {{數量}} 題
4. 挑戰版練習 {{數量}} 題
5. 教師提示語
6. 常見錯誤診斷表
7. 補救教學建議

要求：
- 題目要看得出分層，不只是改數字
- 語氣清楚，不要寫得像補習班廣告
- 不要使用真實學童資料
- 哪些地方需要人工確認，請在最後單獨列出
```

---

## 建議追加指令

若第一版方向大致正確，可再補下面其中一種要求：

### 追加指令 A：補教師帶領語

```text
請為每一層練習各補 1 句教師帶領提示語，幫助老師在課堂上提問。
```

### 追加指令 B：補教材修訂重點

```text
請把目前教材最需要先修的 3 個地方整理成條列，說明原因。
```

### 追加指令 C：改成低門檻版本

```text
請保留同一個教學目標，但把整份內容改成更適合學習起點較低學童的版本。
```

---

## 人工審查清單

產出後至少檢查以下五點：

- 教學概念是否正確
- 難度分層是否真的不同
- 題目語氣是否符合博幼教學情境
- 補救建議是否對應到常見錯誤
- 有沒有出現需要人工補充但 Agent 沒標出的地方

---

## 最後提醒

這份模板最適合拿來做第一版草稿、差異化練習與補救建議。正式進教材前，仍要由教學人員逐項審稿。
