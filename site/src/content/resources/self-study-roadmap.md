# 自主學習路徑規劃 — 辦公室 AI Agent 實戰入門

> 建議時程：4 週，每週 3–5 小時，合計 16–20 小時

本學習路徑是「辦公室 AI Agent 實戰入門」6 小時實體課程的課後延伸教材。完成課程後，依照以下四週計畫練習，把課堂學到的東西變成日常工作用得到的 Agent 技能。

---

## 學習路徑總覽

| 週次 | 主題 | 建議時數 | 核心產出 |
|------|------|----------|----------|
| 第 1 週 | 基礎概念複習 + 環境建置 | 3–4 小時 | 可運作的 Hermes Agent 開發環境 |
| 第 2 週 | Hermes Agent 核心功能 | 4–5 小時 | 可跨平台互動的 Agent |
| 第 3 週 | 進階操作 | 4–5 小時 | 具備排程與子代理能力的 Agent |
| 第 4 週 | 博幼基金會場景專案 | 5 小時 | 端到端場景實作成果 |

---

## 第 1 週：基礎概念複習 + 環境建置

### 學習目標

- 鞏固 Model-Agent-Harness 三層架構的理解
- 在自己的電腦上建立完整的 Hermes Agent 開發環境
- 確認 API 連線正常，能以 CLI 模式與 Agent 對話

### 建議時數：3–4 小時

### 具體任務

1. 複習課程筆記（30 分鐘）
   - 重新閱讀課堂教材中「AI 生態系概覽」與「認識 AI 模型」兩個章節
   - 用自己的話寫下 Model、Harness、Agent 各自的角色，以及三者之間的關係
   - 確認自己能回答：為什麼光有 AI 模型還不夠？Harness 解決了什麼問題？

2. 環境建置（60–90 分鐘）
   - 確認 Python 3.11 以上已安裝（終端機執行 `python3 --version`）
   - 執行 Hermes Agent 安裝指令：
     ```bash
     curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
     ```
   - 驗證安裝成功：
     ```bash
     hermes --version
     ```
   - 設定 API Key（至少設定一個）：
     ```bash
     export OPENAI_API_KEY="sk-..."
     # 或
     export ANTHROPIC_API_KEY="sk-ant-..."
     # 或
     export GOOGLE_API_KEY="AI..."
     ```

3. 第一次對話（30 分鐘）
   - 啟動 Hermes Agent CLI 模式：`hermes chat`
   - 嘗試以下對話指令，觀察回應差異：
     - 「請用三句話介紹你自己」
     - 「今天是幾月幾號？」（觀察 Agent 是否能查詢即時資訊）
     - 「請幫我把一段英文翻譯成中文：The quick brown fox jumps over the lazy dog.」

4. 閱讀補充材料（60 分鐘）
   - 閱讀 [Harness Paradigm 介紹文章](https://kenhuangus.substack.com/p/chapter-1-the-harness-paradigm-claude)
   - 瀏覽 [Hermes Agent 官方文件](https://hermes-agent.nousresearch.com/) 的 Getting Started 段落
   - 在筆記中記錄三個你仍然感到困惑的問題

### 本週產出物

- [ ] 三層架構理解筆記（手寫或數位均可）
- [ ] Hermes Agent 環境建置完成，`hermes --version` 可正常輸出
- [ ] 第一筆 CLI 對話截圖或記錄
- [ ] 三個待釐清的問題清單

## 第 2 週：Hermes Agent 核心功能

### 學習目標

- 理解並實作 Hermes Agent 的工具使用（Tool Use）機制
- 認識 Agent 的記憶系統（短期記憶、長期記憶）
- 完成至少一個跨平台設定（Telegram / Discord / Slack / WhatsApp 擇一）

### 建議時數：4–5 小時

### 具體任務

1. 工具使用 Tool Use（90 分鐘）
   - 閱讀官方文件中 Tools 章節
   - 啟用 Hermes Agent 內建工具（如網頁搜尋、檔案讀寫）
   - 實作練習：
     - 請 Agent 搜尋某個主題的最新新聞並摘要
     - 請 Agent 讀取一個 CSV 檔案並回答問題
     - 請 Agent 撰寫一段文字並存成文字檔
   - 觀察 Agent 如何決定「何時」以及「如何」使用工具

2. 記憶系統（60 分鐘）
   - 了解 Hermes Agent 的記憶分類：
     - 對話記憶：單次對話中的上下文
     - 技能記憶：從經驗中累積的技能（自學習迴圈）
   - 實驗：先告訴 Agent 你的工作角色和偏好，結束對話後重新啟動，觀察 Agent 是否保留相關資訊
   - 嘗試手動新增一項技能到 Agent 的技能庫

3. 跨平台設定（60–90 分鐘）
   - 選擇一個你常用的通訊平台（建議從 Telegram 開始，設定最簡單）
   - 依照官方文件的 Integrations 章節完成設定
   - 測試：從手機傳訊息給你的 Agent，確認能正常回應
   - 記錄設定過程中遇到的問題與解法

4. 閱讀與反思（30 分鐘）
   - 閱讀 Hermes Agent GitHub 的 README 和範例
   - 想想在你的日常工作中，哪些任務最適合交給 Agent 處理

### 本週產出物

- [ ] 至少完成 3 個工具使用操作的截圖或記錄
- [ ] 記憶系統實驗觀察筆記
- [ ] 一個跨平台的運作連線（手機端可對話）
- [ ] 個人工作場景的 Agent 應用候選清單（至少列 3 個）

## 第 3 週：進階操作

### 學習目標

- 設定排程任務，讓 Agent 定時自動執行工作
- 理解並實作平行子代理（Sub-Agent）架構
- 學會客製化 Agent 技能，打造符合個人需求的能力

### 建議時數：4–5 小時

### 具體任務

1. 排程自動化（90 分鐘）
   - 閱讀官方文件中的 Scheduling 章節
   - 實作以下排程練習：
     - 設定一個每小時執行一次的簡單任務（如查詢天氣）
     - 設定一個每日定時摘要任務（如彙整今日新聞）
     - 設定一個每週報告任務（如每週一早上產生摘要）
   - 觀察排程任務的執行記錄，確認運作正常

2. 平行子代理 Sub-Agent（90 分鐘）
   - 理解子代理的概念：主代理可以將複雜任務拆分給多個子代理平行處理
   - 閱讀官方文件中的 Multi-Agent 章節
   - 實作練習：
     - 建立一個主代理和兩個子代理
     - 設定一個需要子代理協作的任務（例如：一個搜尋資料、一個分析資料，主代理彙整結果）
   - 觀察子代理之間的溝通模式

3. 技能客製化（60–90 分鐘）
   - 了解 Hermes Agent 的技能系統架構
   - 為自己的工作場景建立一個自訂技能：
     - 定義技能名稱和描述
     - 撰寫技能觸發條件
     - 設計技能執行步驟
   - 測試自訂技能，觀察自學習迴圈是否開始累積經驗

4. 沙箱後端探索（30 分鐘）
   - 了解 Hermes Agent 的沙箱後端（Sandbox Backend）安全機制
   - 確認你的 Agent 在執行檔案操作時受到適當的安全限制

### 本週產出物

- [ ] 至少 2 個運作中的排程任務及其執行記錄
- [ ] 子代理協作任務的設定檔和執行結果
- [ ] 一個自訂技能的完整設定
- [ ] 沙箱後端的安全設定檢查清單

## 第 4 週：博幼基金會場景專案

### 學習目標

- 把前三週學到的知識整合到一個真實辦公場景
- 獨立走完從需求分析到 Agent 部署的完整流程
- 產出一個可展示的成果

### 建議時數：5 小時

### 具體任務

1. 場景選擇與需求分析（60 分鐘）
   - 從以下場景中挑選一個，或自行設計：
     - 課輔中心週報彙整 Agent：自動收集各課輔中心的資料，彙整成每週報告
     - 教學會議記錄 Agent：接收教學會議筆記，自動整理成結構化記錄並分發
     - 學童家長來信處理 Agent：分類家長來信、草擬回覆、標記急件
     - 課輔計畫進度監控 Agent：定期追蹤課輔計畫狀態，異常時發送提醒
   - 撰寫簡短的需求文件：
     - 問題描述：目前手動流程的痛點
     - Agent 職責：Agent 需要完成哪些步驟
     - 預期產出：Agent 最終交付什麼結果

2. Agent 設計與實作（120 分鐘）
   - 根據需求設計 Agent 架構：
     - 選擇合適的 AI 模型
     - 設計工具清單（需要哪些工具）
     - 規劃記憶策略（需要記住什麼）
     - 決定是否需要排程或子代理
   - 開始實作：
     - 設定 Agent 基本配置
     - 加入所需工具
     - 撰寫自訂技能
     - 設定排程或觸發條件

3. 測試與調整（60 分鐘）
   - 用真實或模擬資料測試 Agent
   - 記錄測試結果，標注需要改善的地方
   - 調整提示詞、工具設定或流程
   - 重複測試直到結果滿意

4. 成果文件化（60 分鐘）
   - 撰寫簡短的專案報告（1–2 頁）：
     - 場景描述與需求
     - Agent 架構設計
     - 實作過程中的挑戰與解法
     - 最終成果展示（截圖或錄影）
     - 後續改善方向
   - 可選：錄製 3–5 分鐘的操作示範影片

### 本週產出物

- [ ] 需求文件
- [ ] 完整的 Agent 設定檔
- [ ] 測試記錄
- [ ] 專案報告

## 學習建議

### 時間安排

- 每週建議分 2–3 次完成，避免一次吸收過多
- 建議時段：每次 1.5–2 小時
- 進度落後不用追趕，按自己的步調完成就好

### 學習策略

1. 動手做勝過只閱讀：每個概念都搭配實際操作
2. 記錄問題：遇到問題先記下來，自己試 15 分鐘，再尋求協助
3. 與他人交流：加入 Hermes Discord 社群，或在課程群組中分享心得
4. 從小處著手：先讓簡單的功能跑通，再逐步增加複雜度

### 尋求協助的管道

- Hermes 官方 Discord：[https://discord.gg/nousresearch](https://discord.gg/nousresearch)
- Hermes GitHub Issues：[https://github.com/nousresearch/hermes-agent/issues](https://github.com/nousresearch/hermes-agent/issues)
- 課程社群：依照課堂上提供的群組連結加入
- Reddit r/AI_Agents：[https://www.reddit.com/r/AI_Agents/](https://www.reddit.com/r/AI_Agents/)

### 學習完成後的下一步

完成 4 週學習路徑後，你可以：

1. 將場景專案部署到實際工作環境中試行
2. 學習其他 Agent 開發框架（如 LangChain、CrewAI）
3. 嘗試多 Agent 協作的複雜場景
4. 分享你的實作經驗，成為團隊中的 AI Agent 推動者
