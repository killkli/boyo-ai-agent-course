# 第 6 堂：辦公室場景工作坊

## 基本資訊

- **時長**：60 分鐘
- **型態**：分組實作 + Demo 分享 + 課程總結
- **對應學習目標**：6.1 將 Agent 技術應用於博幼基金會的真實業務場景、6.2 完成從需求分析到 Agent 部署的完整流程、6.3 與團隊協作設計 Agent 解決方案、6.4 規劃個人的後續學習路徑

---

## 教學流程

### 第一階段：工作坊說明與分組（5 min）

**學習重點**

- 這是整門課的壓軸：把前五堂學到的知識，用在博幼基金會的真實業務場景
- 每組會拿到一個場景，需要：
  1. 分析需求（什麼工作要自動化？）
  2. 設計 Agent 方案（要用哪些工具？怎麼串起來？）
  3. 實際操作 Hermes 完成（至少做出可運作的原型）
  4. 準備 3 分鐘的成果 Demo
- 評估標準：不是看結果多完美，而是看思路是否清晰、是否善用工具、是否能說出改進方向

---

### 第二階段：分組實作（30 min）

各組拿到自己的場景說明卡後，開始實作。以下為四個場景的完整說明：

#### 場景 A：課輔中心週報彙整

**任務說明**

你是博幼基金會某課輔中心的行政人員，每週需要從各課輔班收集學童學習進度，彙整成一份週報給基金會總部。目前流程：各課輔班老師填寫進度表 → 你手動複製貼上 → 排版 → 寄給總部。這個流程每週花 2-3 小時，而且容易漏掉需協助的事項或特教生的追蹤紀錄。

**目標**：設計一個 Hermes Agent，讓課輔週報彙整流程自動化。

**建議使用的工具**

| 工具 | 用途 |
|------|------|
| `file_read` | 讀取各課輔班提交的進度檔案 |
| `file_write` | 產生彙整後的週報檔案 |
| `scheduler` | 設定每週定時執行 |
| `web_search`（選配） | 查詢教育政策動態加入週報參考 |

**實作步驟提示**

1. **準備測試資料**：建立 3 個模擬的課輔班進度檔案
   ```bash
   mkdir -p ~/workshop-scenario-a
   cat > ~/workshop-scenario-a/puli-center.txt << 'EOF'
   埔里課輔中心 2026 第 21 週進度
   填寫人：陳老師

   本週完成進度：
   - 國小三年級數學：完成除法單元（第 7-9 章），12 位學童中 10 位通過單元測驗
   - 國小五年級國語：完成說明文寫作指導，8 位學童已繳交作文
   - 國中一年級英文：完成過去式句型練習

   學童出席狀況：
   - 應到 32 人，實到 29 人（3 人請假）
   - 小安連續第二週缺席，已請社工追蹤家庭狀況

   需協助事項：
   - 三年級數學有 2 位學童除法概念仍不穩固，需要個別輔導教材
   - 電腦教室投影機故障，影響數位教學進行

   特教生追蹤：
   - 小傑（注意力不足過動症）：本週使用番茄鐘學習法，專注時間從 10 分鐘提升至 15 分鐘
   EOF

   cat > ~/workshop-scenario-a/zhudong-center.txt << 'EOF'
   竹東課輔中心 2026 第 21 週進度
   填寫人：林老師

   本週完成進度：
   - 國小四年級自然：完成植物觀察單元，學童完成校園植物調查報告
   - 國小六年級數學：完成圓面積計算，11 位學童中 9 位通過測驗
   - 國中二年級社會：完成台灣地理中部區域教材

   學童出席狀況：
   - 應到 28 人，實到 27 人（1 人病假）
   - 本週出席率穩定

   需協助事項：
   - 六年級數學有 2 位學童對圓面積公式理解困難，需要教具輔助
   - 下週自然課需要放大鏡 15 組，目前中心僅有 8 組

   特教生追蹤：
   - 小庭（學習障礙）：使用圖像化數學教材後，計算正確率從 40% 提升至 65%
   EOF

   cat > ~/workshop-scenario-a/xinpu-center.txt << 'EOF'
   新埔課輔中心 2026 第 21 週進度
   填寫人：黃老師

   本週完成進度：
   - 國小二年級國語：完成造句練習單元，15 位學童全數通過
   - 國小四年級數學：完成分數加減，13 位學童中 11 位通過測驗
   - 國中一年級數學：完成一元一次方程式基礎

   學童出席狀況：
   - 應到 26 人，實到 24 人（1 人請假、1 人未到未請假）
   - 小豪未到未請假，已致電家長了解情況

   需協助事項：
   - 四年級數學有 2 位學童分數概念薄弱，需要國小低年級的複習教材
   - 中心冷氣設備老舊，夏季將至需要評估更換

   特教生追蹤：
   - 小恩（自閉症類群）：本週情緒穩定，在小組學習中能與同學配合完成任務
   EOF
   ```

2. **設計提示詞**：讓 Hermes 讀取所有檔案，按統一格式彙整
   ```
   請依序讀取以下檔案：
   - ~/workshop-scenario-a/puli-center.txt
   - ~/workshop-scenario-a/zhudong-center.txt
   - ~/workshop-scenario-a/xinpu-center.txt

   將內容彙整為一份課輔週報，格式如下：
   # 課輔週報 — 2026 第 21 週

   ## 各中心進度
   ### [中心名稱]
   - 本週完成進度：...
   - 學童出席狀況：...
   - 需協助事項：...
   - 特教生追蹤：...

   ## 整體摘要
   [一段話總結本週重點]

   ## 需總部關注事項
   - ...

   ## 下週追蹤清單
   - ...

   將結果存到 ~/workshop-scenario-a/weekly-report.md
   ```

3. **加入排程**：設定每週五下午自動執行

**完成後你可以驗證**

- 一份格式統一的課輔週報 Markdown 檔案
- 一個排程設定（展示用即可）
- 能說明：如果要接上真實的 Email 收信或雲端表單，還需要哪些工具或整合

#### 場景 B：教學會議記錄整理與待辦追蹤

**任務說明**

你是博幼基金會課輔中心的教學組長，每週有多場教學研討會、個案研討會議，每次會議後需要整理記錄、標記教學行動項目、追蹤負責老師和完成期限。目前用手動整理，容易遺漏待辦事項，也難以追蹤個案學童的後續處理狀況。

**目標**：設計一個 Hermes Agent，自動整理教學會議記錄並產出結構化的待辦清單。

**建議使用的工具**

| 工具 | 用途 |
|------|------|
| `file_read` | 讀取會議記錄原始內容 |
| `file_write` | 產出整理後的會議記錄和待辦清單 |
| `web_search`（選配） | 查詢會議中提到的教材或教法參考資料 |

**實作步驟提示**

1. **準備測試資料**：建立一份模擬的教學研討會記錄
   ```bash
   mkdir -p ~/workshop-scenario-b
   cat > ~/workshop-scenario-b/meeting-raw.txt << 'EOF'
   教學研討會 2026/05/21
   出席：教學組長張雅芬、課輔老師陳怡君、課輔老師林志明、社工師王美玲、特教老師趙心怡

   張雅芬：上週五年級數學教材「分數乘法」的修訂版已經在各中心試用，竹東中心回饋學童理解度明顯提升。下一階段要處理的是六年級「速率」單元的教材調整，預計下週三完成初稿。

   林志明：國中一年級英文教材的音檔有部分錯誤，已經聯繫錄音單位修正。修正版預計本週四完成。不過需要陳怡君老師幫忙確認更新後的音檔是否與教材內容一致。

   陳怡君：教材確認沒問題，但志明的教學進度表跟實際教材版本有出入，請在週三前更新進度表。

   王美玲：埔里中心的小安（國小四年級）家庭狀況有新變化，母親住院中，目前由祖母照顧，學童情緒不穩定。社工端已啟動關懷機制，需要特教老師協助評估是否需要調整學習計畫。

   趙心怡：小安的狀況我會在下週一前往埔里中心進行觀察評估。另外，暑期課程的特教融合班規劃，我已經完成初版方案，預計下週提交教學組審查。

   張雅芬：暑期密集課輔計畫的師資培訓日程需要盡快確認，目前有 5 位新進課輔老師需要完成培訓。另外，數位學習平台的帳號開通進度落後，請王美玲協助追蹤。

   結論：六年級「速率」教材初稿下週三完成、英文音檔修正本週四完成、教學進度表週三前更新、小安個案由趙心怡下週一評估、暑期特教融合班方案下週提交、暑期師資培訓日程盡快確認、數位平台帳號開通請社工端協助追蹤。
   EOF
   ```

2. **設計提示詞**：讓 Hermes 整理會議記錄，提取待辦事項
   ```
   請讀取 ~/workshop-scenario-b/meeting-raw.txt，進行以下整理：

   1. 產出一份格式化的會議記錄，包含：會議名稱、日期、出席者與職稱、討論內容摘要
   2. 提取所有行動項目（Action Items），格式：
      - [ ] 待辦事項描述 | 負責人 | 截止日期 | 優先級（P0/P1/P2）
   3. 如果有提到個案學童，額外標記「個案追蹤」分類
   4. 如果有提到阻塞或依賴關係，額外標記出來

   將結果存到 ~/workshop-scenario-b/meeting-notes.md
   ```

3. **進階挑戰**（時間允許）：讓 Hermes 比較多週的會議記錄，找出重複出現的待辦或一直未解決的個案

**完成後你可以驗證**

- 一份結構化的教學會議記錄
- 一份有負責人、截止日期、優先級的待辦清單
- 個案學童的追蹤項目清單
- 能說明：如果要持續追蹤待辦完成狀態，需要怎麼設計

#### 場景 C：學童家長來信分類與回覆建議

**任務說明**

你是博幼基金會課輔中心的社工，每天收到數封家長來信或訊息，需要分類（課程詢問/學童狀況反映/家長求助/資源申請/感謝回饋）、判斷優先級、並提供回覆建議給社工團隊參考。目前完全依賴人工閱讀和分類，效率低且分類標準不一致，有時候緊急的求助訊息沒有被及時注意到。

**目標**：設計一個 Hermes Agent，自動分類家長來信並產出回覆建議。

**建議使用的工具**

| 工具 | 用途 |
|------|------|
| `file_read` | 讀取模擬的家長來信 |
| `file_write` | 產出分類結果和回覆建議 |
| `web_search`（選配） | 搜尋相關社福資源資訊以提供準確回覆 |

**實作步驟提示**

1. **準備測試資料**：建立 3 封模擬家長來信
   ```bash
   mkdir -p ~/workshop-scenario-c
   cat > ~/workshop-scenario-c/email-01.txt << 'EOF'
   寄件者：劉媽媽（埔里中心學童家長）
   主旨：詢問暑期課輔班報名

   你好，

   我的小孩小宇目前在埔里中心參加課後輔導，想請問今年暑期的密集課輔班什麼時候開始報名？
   去年我們很受益於暑期課輔，孩子開學後在班上的成績進步很多。
   今年暑假我們也想讓弟弟一起參加，他剛升上國小三年級，符合資格嗎？
   另外想確認暑期課輔的上課地點是在原來的埔里中心，還是會有變動？

   謝謝！
   劉媽媽
   EOF

   cat > ~/workshop-scenario-c/email-02.txt << 'EOF'
   寄件者：陳爸爸（竹東中心學童家長）
   主旨：急！孩子在學校被欺負

   你好，

   我的女兒小芳這幾天回家都不說話，今天晚上我才問出來，她在學校被幾個同學排擠，還被叫難聽的綽號。
   她現在連課輔班都不太想去，說怕同學笑她去補習還是考不好。
   我跟她媽媽都很擔心，不知道該怎麼處理。她老師說會注意，但我覺得情況沒有改善。
   你們可以幫忙嗎？有沒有什麼方法可以幫小芳？

   陳爸爸
   EOF

   cat > ~/workshop-scenario-c/email-03.txt << 'EOF'
   寄件者：邱先生（新埔社區居民）
   主旨：建議增加英語課程

   你好，

   我是新埔在地的社區志工，長期關注偏鄉教育議題。一直很佩服博幼基金會在偏鄉課輔的貢獻。

   我有一個建議：在課輔課程中增加英語口說練習的機會。現在國中會考英語聽力佔分比例越來越高，但我觀察到很多偏鄉孩子缺乏英語口說環境，上國中後跟不上進度。

   如果需要英文志工，我們社區有幾位退休英語教師可能有意願幫忙，我可以協助聯繫。

   另外，現在有很多免費的線上英語學習資源，也許你們可以評估看看是否適合導入課輔課程。

   邱先生
   EOF
   ```

2. **設計提示詞**：讓 Hermes 批次分類並建議回覆
   ```
   請依序讀取以下三封信件：
   - ~/workshop-scenario-c/email-01.txt
   - ~/workshop-scenario-c/email-02.txt
   - ~/workshop-scenario-c/email-03.txt

   對每封信進行：
   1. 分類（課程詢問/學童狀況反映/家長求助/資源申請/感謝回饋）
   2. 優先級判斷（緊急/高/中/低）
   3. 情緒判斷（正面/中性/焦慮/急切）
   4. 回覆建議（包含建議的回覆主旨和內容重點，不寫完整回覆，只列重點）

   將結果整理成表格格式，存到 ~/workshop-scenario-c/classification.md
   ```

**完成後你可以驗證**

- 一份信件分類表格（分類、優先級、情緒、回覆重點）
- 每封信的回覆建議大綱
- 能說明：如果要整合真實的 Email 信箱或通訊軟體，需要怎麼做 API 串接

#### 場景 D：課輔計畫進度監控與異常提醒

**任務說明**

你是博幼基金會教育處專員，負責監控 3 個進行中課輔計畫的進度。每週需要彙整各計畫狀態、識別落後或風險項目、並主動通知計畫負責人。目前用試算表手動追蹤，容易漏掉即將逾期或已經落後的里程碑。

**目標**：設計一個 Hermes Agent，自動分析課輔計畫進度並標記異常。

**建議使用的工具**

| 工具 | 用途 |
|------|------|
| `file_read` | 讀取各課輔計畫的進度資料 |
| `file_write` | 產出監控報告和異常清單 |
| `scheduler` | 設定每週定時檢查 |
| `web_search`（選配） | 查詢教育部相關政策或補助方案動態 |

**實作步驟提示**

1. **準備測試資料**：建立 3 個模擬課輔計畫的進度檔案
   ```bash
   mkdir -p ~/workshop-scenario-d
   cat > ~/workshop-scenario-d/project-summer.txt << 'EOF'
   計畫：暑期密集課輔計畫
   負責人：埔里中心主任 許雅芳
   預計完成日：2026-07-31
   進度：65%

   里程碑：
   [完成] 師資招募與培訓 — 原訂 4/15，實際 4/14
   [完成] 教材準備完成 — 原訂 5/01，實際 5/03
   [進行中] 學童篩選與報名 — 原訂 5/20，目前進度 80%
   [未開始] 暑期正式開課 — 原訂 7/01
   [未開始] 期中學習評量 — 原訂 7/15
   [未開始] 結業成果展 — 原訂 7/31

   風險：學童篩選作業進度輕微落後，部分中心的家長同意書回收率偏低，可能影響報名人數。教材準備也延遲了 2 天，可能壓縮到開課前的準備時間。
   EOF

   cat > ~/workshop-scenario-d/project-digital.txt << 'EOF'
   計畫：偏鄉數位學習推廣計畫
   負責人：數位教育組長 鄭明輝
   預計完成日：2026-06-30
   進度：40%

   里程碑：
   [完成] 數位設備盤點 — 原訂 4/10，實際 4/18（落後 8 天）
   [完成] 平台帳號開通 — 原訂 4/30，實際 5/08（落後 8 天）
   [進行中] 課輔老師數位教學培訓 — 原訂 5/20，目前進度 25%
   [未開始] 數位課程試行 — 原訂 6/01
   [未開始] 學童數位能力前測 — 原訂 6/10
   [未開始] 正式導入上線 — 原訂 6/30

   風險：已經連續兩個里程碑落後，目前進度 40% 但時間已過 55%。設備採購流程比預期冗長，加上部分課輔老師對數位工具不熟悉，培訓進度緩慢。如果不調整時程或增加培訓資源，很可能無法在暑期前完成導入。
   ```

## 關鍵概念

| 概念 | 一句話解釋 |
|------|-----------|
| 場景化設計 | 從真實工作痛點出發，設計 Agent 解決方案 |
| 工具組合 | 把多個工具串接起來，完成複雜的工作流程 |
| 原型思維 | 先做出最小可運作版本，再迭代改進 |
| 團隊協作 | 分工合作：有人分析需求、有人操作 Agent、有人整理成果 |
| 迭代改進 | Agent 方案不是一次到位，需要持續調整優化 |
| 後續學習路徑 | 根據個人目標（應用/開發/管理），選擇不同的深化方向 |

## 延伸活動（若有餘裕時間）

### 跨組合作挑戰

如果有額外 10-15 分鐘，讓不同場景的組別交流：

- 場景 A（週報彙整）+ 場景 D（課輔進度監控）：能不能讓週報 Agent 也做計畫進度監控？各中心回報的進度資料，能否同時用來產出週報和計畫健康度報告？
- 場景 B（教學會議記錄）+ 場景 C（家長來信）：能不能讓會議記錄中提到的個案追蹤，自動比對家長來信中的相關內容？例如會議中討論小安的狀況，同時系統注意到小安的家長也有來信反映？

思考看看：Agent 方案不是孤立的，不同的能力可以組合出更強大的解決方案。在博幼的日常工作中，課輔進度、會議追蹤、家長溝通這些環節是互相關聯的。

### 一句話電梯簡報

每位學員用一句話（30 秒）回答：「如果回到中心，你會怎麼跟主任說明今天學到了什麼？」

這個活動幫助你把課程收穫內化為自己的語言，也練習在機構中推廣 AI Agent 的溝通能力。
