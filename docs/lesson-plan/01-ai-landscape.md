# AI 生態系概覽：從聊天機器人到自主 Agent

## 基本資訊

- **時長**：50 分鐘
- **型態**：講授 + 互動討論 + 即時示範
- **對應學習目標**：
  - 1.1 了解 AI 應用從 Chatbot 到 Agent 的演進歷程
  - 1.2 理解 Model-Agent-Harness 三層架構的基本輪廓
  - 1.3 認識目前職場中 AI 的實際應用場景
  - 1.4 能夠評估自身工作中可被 AI 輔助的環節

---

## 教學流程

### 第一階段：開場與破冰（8 分鐘）

**講授要點：**

- 課程簡介：這是一門 6 小時的實作課，目標是讓每位學員理解 AI Agent 的運作原理，並親手操作一個開源 Agent 框架
- 快速調查（舉手）：
  - 「你每天工作中使用 AI 工具的頻率？」（從未 / 偶爾 / 每天 / 重度依賴）
  - 「你目前用過哪些 AI 工具？」（ChatGPT / Copilot / Gemini / 其他）
- 建立共同語言：今天要從「使用者」視角切換到「理解者」視角

**互動：**

- 講師準備一個即時投票（可用手機掃 QR code，或直接舉手統計），將結果投影在白板上
- 目的是讓學員意識到：多數人還停留在「對話式使用」，這正是今天要突破的起點

---

### 第二階段：AI 應用的演進路線圖（15 分鐘）

**講授要點：**

在白板或投影片上畫出一條時間線，標示四個階段：

**階段一：規則系統（Rule-Based, 2010 年代前）**
- 例如：自動回覆 Email 範本、Excel 巨集、客服轉接規則
- 特徵：人類寫好所有規則，系統只是執行者

**階段二：對話式 AI（Chatbot, 2022-2023）**
- ChatGPT 的出現讓大眾第一次感受到「AI 可以理解我」
- 使用方式：一問一答、單次互動、人類主導所有決策
- 限制：每次對話都是獨立的，AI 不會主動幫你完成一串任務

**階段三：AI 助理（AI Assistant, 2023-2024）**
- 例如：Copilot 整合在 Office 裡、Notion AI、Cursor 程式碼助手
- 進步：AI 開始有上下文，能看到你的文件、程式碼、工作環境
- 限制：仍然是「你問一步，它做一步」，不會自己規劃完成路徑

**階段四：自主 Agent（Autonomous Agent, 2024-）**
- 定義：給定一個目標，Agent 能自行分解任務、選擇工具、執行步驟、檢查結果
- 關鍵差異：從「人類下指令」變成「人類設目標」
- 實例：AI Agent 自動監控信箱、分類信件、起草回覆、排程會議，一連串動作不需要人類逐步指示

**視覺輔助：**

```
規則系統          對話式 AI         AI 助理           自主 Agent
(規則 → 執行)    (問 → 答)        (上下文 → 輔助)    (目標 → 自主完成)
    |                |                 |                  |
    └──── 人類控制力逐漸降低，AI 自主性逐漸提高 ────┘
```

---

### 第三階段：三層架構預告（12 分鐘）

**講授要點：**

告訴學員：「要理解 Agent，我們需要一個思維框架。接下來的整門課都圍繞這個架構。」

用「公司」做比喻介紹三層架構：

| 層級 | 名稱 | 公司比喻 | 職責 |
|------|------|----------|------|
| 第一層 | **Model（模型）** | 員工的專業能力 | 理解語言、生成文字、推理判斷 |
| 第二層 | **Harness（控管框架）** | 公司的規章制度與管理流程 | 限制工具使用、管理狀態、處理錯誤、追蹤資源 |
| 第三層 | **Agent（智能體）** | 一位完整的員工 | 將 Model 的能力加上 Harness 的控管，整合為一個能自主行動的實體 |

**白板板書：**

```
┌─────────────────────────────┐
│         Agent（智能體）       │  ← 我們最終要建構的東西
│  ┌───────────────────────┐  │
│  │   Harness（控管框架）  │  │  ← 規則、限制、安全管理
│  │  ┌─────────────────┐  │  │
│  │  │  Model（模型）   │  │  │  ← 智慧的核心來源
│  │  └─────────────────┘  │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
```

**為什麼需要 Harness？**

用一個生活化的例子說明：
- 想像一位非常聰明的實習生（Model），他能理解任何指令、知識淵博
- 但如果他可以直接動用公司信用卡、刪除資料庫、對外發送 Email，沒有任何管控，你敢讓他自主工作嗎？
- Harness 就是「實習生的主管 + 公司規章 + 權限卡」：讓聰明的能力在安全的範圍內發揮

**本課程對應：**
- 今天（第 1 堂）：看見全貌
- 第 2 堂：深入理解 Model 層
- 第 3 堂：深入理解 Harness 層
- 後續課堂：用 Hermes Agent 框架實作完整的 Agent

---

### 第四階段：職場 AI 現況（5 分鐘）

**講授要點：**

快速展示幾個真實的職場 AI 應用場景，讓學員感受到這已經在發生：

| 工作領域 | 已被改變的任務 | AI 扮演的角色 |
|----------|---------------|-------------|
| 行銷 | 文案撰寫、社群排程、競品分析 | 從草擬到優化的全流程輔助 |
| 人資 | 履歷篩選、面試問題生成、員工 FAQ | 自動化初篩 + 24 小時問答 |
| 財務 | 發票辨識、報表摘要、異常偵測 | 資料擷取 + 模式識別 |
| 客服 | 自動回覆、情緒分析、升級判斷 | 第一線回應 + 人類處理複雜案件 |
| 程式開發 | 程式碼生成、Debug、測試撰寫 | 配對編程夥伴 |

**關鍵訊息：**
- AI 不是要取代你，而是改變你的工作方式
- 「會用 AI 的人」和「不會用 AI 的人」之間的生產力差距正在快速擴大
- 從 Chatbot 到 Agent，是從「工具」到「同事」的轉變

---

### 第五階段：學員分享與總結（10 分鐘）

**互動活動：小組討論**

- 將學員分成 3-4 人小組
- 討論問題（投影在螢幕上）：
  1. 你目前工作中，哪一個重複性任務最希望 AI 能幫你處理？
  2. 如果有一個 AI「同事」可以自主完成任務，你最想讓它做什麼？你會擔心什麼？
- 每組 5 分鐘討論，然後每組派一人用 1 分鐘分享一個最有代表性的答案

**講師總結：**

- 收斂學員的回答，連結到三層架構：
  - 學員期望的「能做某件事的 AI」= Agent
  - 學員擔心的「亂搞怎麼辦」= 需要 Harness
  - 「夠不夠聰明」= 取決於 Model
- 預告下一堂課：「下一堂我們會深入 Model，看看 Agent 的『大腦』到底是怎麼運作的。」

---

## 關鍵概念

1. **AI 應用的四個演進階段**：規則系統 → 對話式 AI → AI 助理 → 自主 Agent
2. **Model-Agent-Harness 三層架構**：Model 提供智慧，Harness 提供控制，Agent 是兩者的整合
3. **Agent 與 Chatbot 的根本差異**：Agent 能自主規劃和執行多步驟任務，Chatbot 只能被動回應單一指令
4. **Harness 的必要性**：聰明的 AI 沒有管控就像沒有煞車的跑車

---

## 教學提示

- **時間控制**：第二階段的時間線講解最容易超時，每個階段控制在 3-4 分鐘，不要深入技術細節
- **學員程度落差**：有些學員可能從未用過 ChatGPT，有些已經在用 Copilot。開場的舉手調查就是為了掌握程度分佈，後續可根據結果調整深度
- **避免恐懼感**：談到「AI 取代工作」時，保持中立但不製造焦慮。用「工具升級」而非「職位威脅」的語框架構
- **三層架構不用講太深**：本堂只是預告，讓學員有初步印象即可。第 2、3 堂課會分別深入 Model 和 Harness
- **實習生比喻很重要**：這個比喻貫穿整門課，確保學員在此階段就建立清楚的心智模型
- **小組討論時巡場**：注意是否有小組完全沒有動起來，可以適時丟出具體例子引導（例如：「想像每天早上要整理 50 封客訴 Email...」）

## 延伸活動（若有餘裕時間）

- **AI 工具快閃展示**（5 分鐘）：講師現場示範一個簡單的 Agent 行為，例如用 ChatGPT 的 Function Calling 或一個簡單的自動化腳本，展示 AI 不只能聊天，還能做事
- **職場 AI 案例影片**（3 分鐘）：播放一段 1-2 分鐘的企業 AI 應用案例影片（例如 Microsoft Copilot 展示），讓學員看到真實產品中的 Agent 概念
- **願景牆**（5 分鐘）：發便利貼，讓每位學員寫下「我希望 AI Agent 幫我做的一件事」，貼在白板上形成願景牆，作為課程的持續參考
