# 第 5 堂：Hermes Agent 實作

## 基本資訊

- **時長**：50 分鐘
- **型態**：Hands-on Lab（學員跟著操作）
- **對應學習目標**：5.1 完成 Hermes 安裝與設定、5.2 執行第一個 Agent 任務、5.3 啟用並使用多種工具、5.4 觀察自學習迴圈的運作

---

## 教學流程

### 第一階段：環境安裝（10 min）

**目標**：每位學員都成功安裝 Hermes 並完成初始設定。

**步驟 1：開啟終端機（1 min）**

- macOS：開啟「終端機」app（Spotlight 搜尋 Terminal）
- Windows：開啟 PowerShell（建議使用 WSL2，若無則用 PowerShell 亦可）
- 確認終端機可用：輸入 `echo hello`，應該看到 `hello` 回應

**步驟 2：執行安裝腳本（3 min）**

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

**操作說明**：

- 這行指令做三件事：下載安裝腳本、執行安裝、把 `hermes` 指令加到系統路徑
- 安裝過程中會看到進度條，正常情況 1-2 分鐘完成
- 如果看到權限相關錯誤，macOS 可能需要在「系統偏好設定 > 安全性與隱私」中允許執行

**常見問題處理**：

| 問題 | 解法 |
|------|------|
| `curl: command not found` | 先安裝 curl：macOS 用 `brew install curl`，Windows 下載安裝包 |
| 權限被拒 | 加 `sudo`：`sudo curl -fsSL ... \| sudo bash` |
| 網路逾時 | 確認是否在公司防火牆後，可能需要切換到手机熱點 |
| `hermes: command not found`（安裝後） | 關閉終端機重新開啟，或執行 `source ~/.bashrc`（或 `~/.zshrc`） |

**步驟 3：執行初始設定（4 min）**

```bash
hermes setup
```

**設定過程會依序詢問**：

1. **選擇模型供應商**：選 OpenAI 或 Anthropic（依學員持有的 API Key 而定）
2. **輸入 API Key**：貼上你的 API Key（畫面不會顯示字元，這是正常的）
3. **選擇預設沙箱**：建議選 Docker（若未安裝 Docker 則選 local）
4. **確認設定**：輸入 `y` 確認

**注意事項**：

- API Key 可以到 platform.openai.com 或 console.anthropic.com 申請
- API Key 是你的個人憑證，**不要分享給他人**，也不要貼到聊天群組或文件中
- 如果不小心洩漏了 API Key，立即到平台上重新產生一組新的
- 安裝完成後會看到「Hermes is ready!」的訊息

**隱私保護提醒（實作前必讀）**：

接下來我們要開始跟 AI 模型對話了。請務必遵守以下規則：

- **不要輸入真實姓名**：用「小明」「小華」等化名代替
- **不要輸入個案內容**：用虛構的範例資料來練習
- **不要輸入任何密碼或 API Key 到對話中**：剛才輸入的 API Key 是設定階段，不算對話內容
- 如果練習中需要文件資料，請使用課程提供的範例檔案，不要使用工作中的真實文件
- 確認安裝完成後再繼續後續步驟

**快速驗證**：

```bash
hermes --version
hermes config show
```

應能看到版本號和目前的設定摘要。

### 第二階段：第一個任務 — 讓 Hermes 幫你整理文件（10 min）

學員親身體驗 Agent 從接收指令到完成任務的完整流程。

**步驟 1：啟動互動模式（2 min）**

```bash
hermes chat
```

進入後會看到 Hermes 的提示符號，表示 Agent 已就緒。

**步驟 2：建立測試用檔案（2 min）**

準備一些測試素材。在另一個終端機視窗執行：

```bash
mkdir -p ~/hermes-workshop
cat > ~/hermes-workshop/notes.txt << 'EOF'
週一：課輔班開課，國小三年級組 12 位學童全勤，數學單元「分數入門」進度正常
週二：教材修訂會議，決議將高年級閱讀理解教材補充 3 篇科普文章
週三：個案研討會，社工師報告小明的家庭訪視狀況，需安排特教老師介入
週四：家長座談會，8 位家長出席，多數關心暑假課輔續辦規劃
週五：課後活動日，美術老師帶領創意手作，需在本週日前完成活動成果拍照與歸檔
EOF
```

**步驟 3：下達整理任務（6 min）**

回到 Hermes 對話視窗，輸入：

```
請讀取 ~/hermes-workshop/notes.txt 這個檔案，整理這週的課輔中心工作紀錄，把內容整理成：
1. 一份條列式的「本週課輔中心工作摘要」，按重要性排序
2. 標記出需要後續跟進的事項（附上截止日期）
3. 把結果存成 ~/hermes-workshop/summary.md
```

**操作說明**：

- 觀察 Hermes 的行為：它會先讀取檔案、分析內容、整理格式、再寫入新檔案
- 這就是「Model 規劃 → Tools 執行」的流程在實際運作
- 注意看終端機上的輸出，會顯示 Agent 正在使用哪些工具

**完成後你可以驗證**：

檢查 `summary.md` 的內容，確認是否包含：
- 按重要性排序的工作摘要
- 標記了需要後續跟進的事項（附上截止日期）
- 格式清晰、可讀性高

**驗證**：

```bash
cat ~/hermes-workshop/summary.md
```

### 第三階段：工具啟用 — 網頁搜尋、檔案操作、排程（15 min）

**步驟 1：查看可用工具（2 min）**

```bash
hermes tools list
```

會列出所有已安裝和可啟用的工具。說明：

- 已啟用（enabled）：可直接使用
- 可啟用（available）：需要額外設定才能使用
- 每個工具旁邊會標示風險等級（低/中/高）

**步驟 2：啟用網頁搜尋工具（4 min）**

```bash
hermes tools enable web_search
```

回到 Hermes 對話中測試：

```
幫我搜尋「偏鄉教育數位化工具 2026」，找出 3 個重點，整理成簡短摘要。
```

**說明**：

- Hermes 會呼叫網頁搜尋工具、閱讀搜尋結果、整理重點
- 觀察：Agent 自己決定搜尋幾次、閱讀哪些結果、如何整理
- 搜尋 + 閱讀 + 摘要，一次完成 — 這就是多工具搭配的效果

**步驟 3：啟用排程工具（4 min）**

```bash
hermes tools enable scheduler
```

測試排程功能：

```
設定一個排程任務：每天早上 9 點，讀取 ~/hermes-workshop/notes.txt，
如果檔案有更新，就自動產生新的課輔中心工作摘要覆蓋 ~/hermes-workshop/summary.md。
```

**說明**：

- 排程工具讓 Agent 從「被動等人下指令」變成「主動定期執行」
- 課輔中心的日常自動化就是這樣開始的 — 把重複性行政工作交給 Agent
- 實際場景中，可以排程彙整每日出勤紀錄、檢查家長來信、追蹤個案進度等

**步驟 4：認識工具啟用的安全機制（5 min）**

**範例展示**：

```bash
# 查看工具的風險等級
hermes tools info file_write
```

會顯示：

```
工具名稱：file_write
風險等級：中
需要確認：是（寫入檔案前會詢問使用者）
描述：寫入或建立檔案
```

**練習與討論**：

- 想想看：「如果有一個工具叫 `file_delete`（刪除檔案），你覺得風險等級應該是什麼？需要確認嗎？如果 Agent 誤刪了學童的學習記錄檔案，會有什麼後果？」
- 重點：「最小權限原則」— 只啟用需要的工具，高風險工具務必保持確認機制

### 第四階段：自學習迴圈 — 觀察 Hermes 如何學習（10 min）

**步驟 1：執行一個重複性任務（4 min）**

```
請建立一個新的筆記檔案 ~/hermes-workshop/notes-week2.txt，內容如下：

「記錄一：國小五年級課輔班，本週英語單元測驗，8 位學童中有 6 位達標
記錄二：社工家訪報告，訪視 3 戶家庭，其中 1 戶需要轉介社福資源
記錄三：教學資源盤點，自然科學實驗器材需補購顯微鏡 2 台
記錄四：新進課輔老師到職，需安排教材熟悉與觀課時程」

然後用和上次相同的方式整理成課輔中心工作摘要，存到 ~/hermes-workshop/summary-week2.md。
```

**步驟 2：觀察學習效果（4 min）**

觀察重點：

- 第一次整理時，Hermes 可能花了 4-5 步：讀取 → 分析 → 規劃格式 → 撰寫 → 存檔
- 第二次整理類似內容時，步驟可能減少到 2-3 步：讀取 → 直接整理存檔
- Hermes 把第一次成功的「整理課輔中心工作紀錄」流程記錄為「技能」

**查看技能記錄**：

```bash
hermes skills list
```

會顯示 Hermes 已經累積的技能清單，可能看到：

```
技能名稱                    | 使用次數 | 上次使用
整理課輔中心工作紀錄為摘要 | 2       | 剛剛
搜尋並摘要網頁            | 1       | 10 分鐘前
```

**說明**：

- 自學習迴圈的運作方式：
  1. Agent 執行任務 → 記錄過程和結果
  2. 任務成功 → 把「成功路徑」存為技能
  3. 下次遇到類似任務 → 優先嘗試已學到的技能
  4. 技能越用越熟練，步驟越來越精簡
- 這不是模型在「重新訓練」，而是把成功的工作流程模板化
- 類比：就像你第一次做蛋餅要看食譜，做過幾次後就會背了

**步驟 3：清理（2 min）**

```bash
hermes skills show 整理課輔中心工作紀錄為摘要
```

查看技能的具體內容，理解「Agent 學到的東西長什麼樣子」。

### 第五階段：總結與預告（5 min）

**總結重點**

1. Hermes 的安裝只需要一條指令加上互動式設定
2. Agent 的工作流程：接收任務 → 規劃步驟 → 呼叫工具 → 產出結果
3. 工具是 Agent 能力的邊界 — 啟用越多工具，Agent 能做的事越多，但風險也越高
4. 自學習迴圈讓 Agent 越用越聰明，任務執行效率會逐步提升

**預告下一堂**

- 下一堂（第 6 堂）是辦公室場景工作坊
- 學員會分組，選擇一個博幼基金會的真實業務場景，用今天學到的 Hermes 技能來解決
- 先想一想：在課輔中心或行政工作中，有哪些重複性任務適合交給 Agent？
- 建議今晚回家再多練習一下 Hermes，越熟悉操作，下堂課越順利

## 關鍵概念

| 概念 | 一句話解釋 |
|------|-----------|
| Hermes 安裝 | 一行指令安裝 + 互動式設定，幾分鐘即可開始使用 |
| 互動模式 | `hermes chat` 進入對話式操作，像跟一個助理聊天 |
| 工具啟用 | `hermes tools enable <工具名>` 擴展 Agent 能力 |
| 工具風險等級 | 每個工具有低/中/高的風險分級，高風險需確認 |
| 排程任務 | 讓 Agent 定時自動執行，把重複工作自動化 |
| 自學習迴圈 | Agent 記錄成功經驗，下次遇到類似任務更高效 |
| 技能累積 | 學到的能力以模板形式保存，可查看和重複使用 |

## 延伸活動（若有餘裕時間）

### 挑戰：用 Hermes 完成一個「跨工具」任務

給自己 5 分鐘，嘗試完成以下任務（需要同時使用多個工具）：

```
搜尋「偏鄉教育數位化工具」，整理重點，
然後把結果存成 ~/hermes-workshop/edu-tech-updates.md，
最後設定一個排程：每週一早上 10 點重新搜尋並更新這個檔案。
```

這個任務會用到：網頁搜尋 → 內容整理 → 檔案寫入 → 排程設定，是工具組合的進階應用。

### 探索：查看 Hermes 的對話記錄

```bash
hermes history
```

回顧剛才所有對話，理解 Memory（對話歷史）是如何被保存的。
