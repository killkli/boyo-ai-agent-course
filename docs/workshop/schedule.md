# Hermes Agent 全天實作工作坊 — 課表

## 基本資訊

- **課程名稱**：Hermes Agent 全天實作工作坊
- **時長**：6 小時教學時間（含休息與午餐約 7 小時 50 分鐘）
- **型態**：全程 Hands-on 實作
- **對象**：已完成「辦公室 AI Agent 實戰入門」前四堂，或具備相當基礎的在職人士
- **先備知識**：了解 Model-Harness-Agent 三層架構、基本終端機操作
- **人數建議**：16–24 人（分 4 組，每組 4–6 人）
- **設備需求**：學員自備筆電（已安裝終端機、可上網）

## 各單元摘要

### 開場：歡迎、課程說明與環境確認（25 min）

- 課程目標與全天流程說明
- 學員自我介紹（一句話：工作上最想自動化的任務是什麼？）
- 分組（4 組，每組 4–6 人）
- 確認終端機與網路連線正常

---

### Lab 1：Hermes 安裝與基礎操作（45 min）

從零開始安裝 Hermes，完成第一個 Agent 任務。

**內容**

1. 安裝 Hermes Agent 並完成初始設定（15 min）
2. 執行第一個任務：讓 Hermes 整理一筆工作筆記（15 min）
3. 觀察 Agent 的「規劃 → 執行 → 產出」流程（10 min）
4. 驗證產出結果（5 min）

**學員產出**：每位學員完成 Hermes 安裝，成功產出第一份整理後的文件。

**對應原課程**：第 5 堂「第一階段：環境安裝」+「第二階段：第一個任務」

---

### Lab 2：工具系統深度探索（50 min）

認識 Agent 的能力邊界，學會安全地擴展工具。

**內容**

1. 認識工具清單、風險等級與安全機制（10 min）
2. 啟用網頁搜尋工具，完成搜尋 + 摘要任務（10 min）
3. 啟用檔案操作工具，完成讀取 + 分析 + 寫入任務（10 min）
4. 實作練習：設計一個「搜尋 → 整理 → 寫檔」三步驟任務（15 min）
5. 工具安全討論：最小權限原則（5 min）

**學員產出**：學員能同時使用 2 種以上工具完成多步驟任務。

**對應原課程**：第 5 堂「第三階段：工具啟用」

---

### Lab 3：自動化流程與自學習迴圈（50 min）

讓 Agent 從被動回應變成主動執行，並觀察學習效果。

**內容**

1. 啟用排程工具，建立定期自動執行的任務（15 min）
2. 觀察自學習迴圈：重複類似任務，比較效率差異（15 min）
3. 查看 Hermes 的技能記錄（10 min）
4. 實作：建立一個完整的自動化工作流（排程 + 檔案處理）（10 min）

**學員產出**：學員建立至少一個可自動執行的工作流，並理解自學習機制。

**對應原課程**：第 5 堂「第四階段：自學習迴圈」+ 第三階段排程部分

---

### Lab 4：辦公室場景實作（一）— 從需求到原型（60 min）

各組選擇一個真實辦公室場景，完成需求分析到原型交付。

**內容**

1. 場景說明與選擇（各組從 A/B/C/D 四選一）（5 min）
2. 需求分析：拆解工作流程，找出可自動化的環節（10 min）
3. 準備測試資料（5 min）
4. 實作第一版原型（35 min）
5. 原型驗證：確認可運作（5 min）

**四個場景**

| 場景 | 主題 | 難度 | 核心工具 |
|------|------|------|----------|
| A | 每日報表彙整 | ★★☆☆☆ | file_read, file_write, scheduler |
| B | 會議記錄整理與待辦追蹤 | ★★★☆☆ | file_read, file_write |
| C | 客戶來信分類與回覆建議 | ★★★☆☆ | file_read, file_write, web_search |
| D | 專案進度監控與異常提醒 | ★★★★☆ | file_read, file_write, scheduler |

**學員產出**：各組完成選定場景的第一版可運作原型。

**對應原課程**：第 6 堂「第二階段：分組實作」（原 30 分鐘擴充為 60 分鐘）

---

### Lab 5：辦公室場景實作（二）— 迭代與優化（50 min）

在原型基礎上迭代改進，加入進階功能。

**內容**

1. 測試原型，找出不足之處（5 min）
2. 迭代優化：改善提示詞、調整工具配置（15 min）
3. 進階挑戰（各場景的延伸任務）（20 min）
   - A：加入異常偵測（標記進度異常的組別）
   - B：跨會議比較，找出重複或衝突的待辦
   - C：加入情緒分析，自動標記高風險客戶
   - D：建立風險預測，提前預警可能的延遲
4. 處理邊界情況與異常（5 min）
5. 撰寫簡短的方案說明，準備 Demo（5 min）

**學員產出**：各組產出優化後的最終版本，完成 Demo 素材準備。

**對應原課程**：第 6 堂場景實作的深化（新增內容）

---

### Lab 6：分組挑戰賽 — 跨場景整合（40 min）

限時挑戰：組合不同場景的能力，解決更大的問題。

**內容**

1. 跨組交流：不同場景的 Agent 方案可以怎麼組合？（5 min）
2. 挑戰題公佈（5 min）
   - 例如：讓「報表彙整 Agent」同時具備「進度監控」能力
   - 例如：讓「會議記錄 Agent」自動產出「客戶信件回覆建議」
3. 限時實作（25 min）
4. 簡短成果分享（5 min）

**學員產出**：體驗 Agent 能力的跨場景組合，思考更大的應用可能性。

**對應原課程**：第 6 堂「延伸活動：跨組合作挑戰」（原為彈性活動，提升為正式單元）

---

### 成果展示、同儕互評與課程總結（40 min）

- 各組 Demo（每組 5 分鐘，含 Q&A）（25 min）
- 同儕互評與「最佳創意獎」投票（5 min）
- 講師總評與回饋（5 min）
- 課程回顧與後續學習路徑（5 min）

**對應原課程**：第 6 堂「第三階段：Demo 分享」+「第四階段：課程總結」
