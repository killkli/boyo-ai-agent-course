# Hermes Agent 全天實作工作坊 — 場景挑戰卡

下午場會從四個辦公室場景中擇一實作。每組的目標不是做出最大功能，而是做出一個能解釋、能驗證、能展示的原型。

## 場景 A：每日報表彙整

### 你要解的問題

把多份零散報表整理成一份主管看得懂的摘要。

### 建議產出

- 一份彙整後的日報或週報
- 異常標記清單
- 缺資料提醒

### 優化方向

- 分主管摘要版與細節版
- 加入跨日比較
- 補上格式不一致與缺欄位處理

## 場景 B：會議記錄整理與待辦追蹤

### 你要解的問題

把原始會議筆記整理成可執行的待辦清單。

### 建議產出

- 結構化會議記錄
- 待辦清單
- 追蹤中的阻塞項目

### 優化方向

- 區分決議、待辦、未定案項目
- 補上截止日與負責人檢查
- 比對多份紀錄找出衝突

## 場景 C：客戶來信分類與回覆建議

### 你要解的問題

快速分辨來信優先級，並給出回覆方向。

### 建議產出

- 信件分類結果
- 優先級標記
- 回覆建議草稿

### 優化方向

- 加入情緒強度判斷
- 分出需要立即回覆與可先內部確認的案件
- 對資訊不足的來信先列出補問項目

## 場景 D：專案進度監控與異常提醒

### 你要解的問題

從多份專案資訊裡找出真正要先處理的風險。

### 建議產出

- 專案狀態摘要
- 風險分級
- 優先處理清單

### 優化方向

- 先整理事實，再做風險判斷
- 加入里程碑落後偵測
- 區分給主管看的摘要與給執行者的行動清單

## Demo 要講清楚的三件事

1. 你們選了什麼場景
2. 第一版原型解決了什麼問題
3. 這一輪迭代後，哪個改動最有價值
