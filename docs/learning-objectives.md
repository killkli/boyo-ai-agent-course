# 學習目標與能力指標

## 總體目標

學員完成 6 小時課程後，能以 Model-Harness-Agent 三層架構理解現代 AI 系統，並具備在博幼基金會場景中實際操作 Hermes Agent 的能力。

## 認知層次對照

依據 Bloom 修訂版分類法：

- 知識 (Remember)：記住事實與基本概念
- 理解 (Understand)：解釋概念、舉例說明
- 應用 (Apply)：在新情境中使用所學
- 分析 (Analyze)：分解、比較、找出關係
- 創造 (Create)：產出新方案或產物

課程的認知層次分佈以「理解」與「應用」為主（約 60%），搭配「知識」打底（20%）和「分析」提升深度（15%），最後以「創造」收尾（5%）。
