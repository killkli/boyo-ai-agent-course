# 常見問題集 — 辦公室 AI Agent 實戰入門

> 問題依照「概念類、技術類、操作類、安全性類、成本類」分類整理。

---

## 一、概念類

### Q1：AI Agent 和聊天機器人有什麼不同？

聊天機器人（如 ChatGPT 網頁版）主要功能是「對話」——你問它問題，它回答。它無法主動執行動作，也無法記住跨對話的資訊（除非使用特定功能）。

AI Agent 則是在聊天機器人的基礎上，增加了三個關鍵能力：
- 工具使用：Agent 可以呼叫外部工具，例如搜尋網路、讀寫檔案、發送郵件、呼叫 API
- 記憶：Agent 能記住過去的互動經驗，從中學習和改進
- 自主規劃：Agent 能將複雜任務拆分為多個步驟，自主決定執行順序

簡單來說，聊天機器人是「只能說話的顧問」，Agent 是「能動手做事的助理」。

---

### Q2：什麼是 Model-Agent-Harness 三層架構？

這是理解 AI Agent 系統的一個框架：

- Model（模型層）：AI 的「大腦」，負責理解語言和生成回應。例如 GPT-4o、Claude Sonnet、Gemini Pro。
- Harness（控管層）：AI 的「制度與流程」，負責管理工具、限制權限、編排執行流程、維護記憶。模型本身只會產生文字，Harness 讓模型能安全地與外部世界互動。
- Agent（代理層）：面向使用者的完整應用，結合 Model + Harness + Tools + Memory，就像一位「遵循公司制度的員工」。

這個架構的關鍵在於：模型提供智慧，Harness 提供控制。光有強大的模型不夠，還需要 Harness 來確保模型能在安全、可控的框架內完成任務。

---

### Q3：為什麼需要 Harness？直接用模型不行嗎？

直接使用模型有幾個限制：

1. 無法存取外部資訊：模型的知識有截止日期，無法即時搜尋網路
2. 無法執行動作：模型只能產生文字，不能讀寫檔案、發送郵件、呼叫 API
3. 沒有持續記憶：每次對話都是全新的，模型不記得上次的內容
4. 缺乏安全邊界：模型可能產生不當內容或執行危險操作，沒有防護機制

Harness 解決了這些問題。它為模型提供了工具介面、記憶系統、安全限制和流程管理，讓模型能成為真正有用的「助手」而非只是「對話者」。

---

### Q4：AI Agent 和 RPA（機器人流程自動化）有什麼不同？

| 比較項目 | RPA | AI Agent |
|----------|-----|----------|
| 運作方式 | 按照預設規則執行固定流程 | 根據情境動態判斷和決策 |
| 適應性 | 流程變更需重新設定 | 能適應新的情況和輸入 |
| 理解能力 | 無法理解非結構化內容 | 能理解自然語言和非結構化資料 |
| 維護成本 | 規則越多，維護越困難 | 透過學習持續改善 |
| 舉例 | 自動將 Excel 資料填入表單 | 閱讀客戶來信，判斷意圖並草擬回覆 |

兩者不是互斥的。AI Agent 可以作為 RPA 的「大腦」，讓自動化流程更具彈性。

---

### Q5：Hermes Agent 的「自學習迴圈」是什麼意思？

自學習迴圈是 Hermes Agent 的一個特色功能。當 Agent 執行任務時，它會從過程中累積經驗，將成功的操作模式轉化為「技能」。下次遇到類似任務時，Agent 可以直接套用已學到的技能，而不需要從頭開始。

例如：
- 第一次你請 Agent 彙整一份報告，它可能需要多次嘗試才找到合適的格式
- Agent 記住了你滿意的格式，將其存為技能
- 下次你請它彙整報告時，它會直接使用已學到的格式

隨著使用時間越長，Agent 的表現會越好。

## 二、技術類

### Q6：Hermes Agent 支援哪些 AI 模型？

Hermes Agent 支援 200+ 模型，涵蓋主流的商業模型和開源模型：

- OpenAI：GPT-4o、GPT-4o Mini、GPT-4 Turbo 等
- Anthropic：Claude Sonnet、Claude Haiku、Claude Opus 等
- Google：Gemini Pro、Gemini Flash 等
- 開源模型：Llama、Mistral、Qwen 等（需透過相容的 API 端點）

你可以在設定檔中指定要使用的模型，也可以讓 Agent 根據任務類型自動選擇最適合的模型。

---

### Q7：Hermes Agent 和 LangChain 有什麼差別？我該學哪個？

| 比較項目 | Hermes Agent | LangChain |
|----------|-------------|-----------|
| 定位 | 開箱即用的 Agent 框架 | 通用 LLM 應用開發工具包 |
| 學習曲線 | 較平緩，適合入門 | 較陡峭，需要更多程式經驗 |
| 適合對象 | 想快速建置實用 Agent | 需要高度客製化 LLM 應用 |
| 功能特色 | 自學習迴圈、跨平台、排程 | 豐富的整合元件和鏈式架構 |

建議：如果你是 Agent 領域的新手，先從 Hermes Agent 入門。等熟悉了 Agent 的核心概念後，再根據需求決定是否需要 LangChain 的彈性。

---

### Q8：Hermes Agent 是免費的嗎？

Hermes Agent 本身是免費的開源軟體，採用 MIT 授權，你可以自由使用和修改。

但使用 Hermes Agent 需要：
- AI 模型的 API 費用：呼叫 GPT-4o、Claude 等模型需要付費（按使用量計費）
- 基礎設施費用：如果部署到雲端伺服器，需要支付伺服器費用（本地使用則免費）

工具免費，但工具所使用的 AI 模型服務需要付費。

---

### Q9：需要會寫程式才能使用 Hermes Agent 嗎？

不需要。Hermes Agent 的基本操作可以完全透過指令和設定檔完成，不需要撰寫程式碼。

本課程的所有實作環節都不要求程式設計能力。但如果具備基本的 Python 概念（如理解變數、字典、函式），會更容易理解進階功能和進行客製化。

---

### Q10：Hermes Agent 可以在公司內部部署嗎？

可以。Hermes Agent 支援以下部署方式：

- 本地部署：在自己的電腦上運行
- 公司伺服器：部署在公司內部伺服器
- 私有雲：部署在公司的雲端環境

如果公司有資料安全要求，可以搭配開源模型（如 Llama）在內部部署，避免資料外傳。不過開源模型的能力通常不如商業模型，需要根據實際需求權衡。

## 三、操作類

### Q11：安裝 Hermes Agent 時遇到錯誤怎麼辦？

常見安裝問題和對應解法：

1. `command not found: hermes`
   - 安裝後需要重新開啟終端機，或執行 `source ~/.bashrc`（bash）或 `source ~/.zshrc`（zsh）

2. `Permission denied`
   - 執行 `chmod +x install.sh` 後再安裝

3. macOS 提示「無法驗證開發者」
   - 前往 系統偏好設定 > 安全性與隱私 > 點選「仍要開啟」

4. Python 版本不符
   - 確認 `python3 --version` 輸出為 3.11 以上。如果不是，請先升級 Python

5. 網路連線問題
   - 確認可以存取 GitHub（`curl -s https://github.com` 是否有回應）
   - 如果在公司網路中，嘗試關閉 VPN 或使用手機熱點

如果以上方法都無法解決，可以到 [Hermes GitHub Issues](https://github.com/nousresearch/hermes-agent/issues) 搜尋類似問題或提問。

### Q12：如何讓 Hermes Agent 連接 Telegram / Discord / Slack？

Hermes Agent 支援多個通訊平台的整合。基本步驟如下：

Telegram（最簡單，建議先從這個開始）：
1. 在 Telegram 搜尋 @BotFather，建立一個新的 Bot
2. 取得 Bot Token
3. 在 Hermes Agent 設定檔中加入 Telegram 設定和 Token
4. 重新啟動 Agent
5. 在 Telegram 中搜尋你的 Bot 並開始對話

Discord：
1. 到 Discord Developer Portal 建立一個 Bot
2. 取得 Bot Token，設定適當的權限
3. 將 Bot 邀請到你的 Discord 伺服器
4. 在 Hermes Agent 設定檔中加入 Discord 設定

Slack：
1. 到 Slack API 頁面建立一個 App
2. 設定 Bot Token 和事件訂閱
3. 將 App 安裝到你的 Slack Workspace

詳細設定步驟請參考 [Hermes 官方文件的 Integrations 章節](https://hermes-agent.nousresearch.com/)。

### Q13：Agent 的回答不準確或不符合預期，怎麼改善？

可以從以下幾個方向調整：

1. 改善提示詞：更具體地描述你想要的結果。例如，把「整理這份資料」改為「將這份銷售資料按照月份分類，列出每月的總營收和年增率」

2. 更換模型：不同模型有不同的強項。如果是複雜推理任務，嘗試使用更強大的模型（如 GPT-4o 或 Claude Sonnet）

3. 提供範例：在提示詞中加入你期望的輸出格式範例

4. 分步執行：將複雜任務拆分為多個簡單步驟，逐步指示 Agent

5. 啟用相關工具：確認 Agent 有啟用完成任務所需的工具（如網頁搜尋、檔案讀取等）

---

### Q14：如何讓 Agent 定時自動執行任務？

Hermes Agent 內建排程功能。你可以在設定檔中定義排程任務：

- 固定間隔：例如每 30 分鐘、每小時執行一次
- 特定時間：例如每天早上 9:00、每週一上午 10:00
- Cron 表達式：使用標準的 cron 語法定義更複雜的排程

設定排程時需要指定：
- 排程時間（間隔或特定時間）
- 要執行的任務描述
- 結果的通知方式（透過 CLI、Telegram、Email 等）

## 四、安全性類

### Q15：我的資料安全嗎？使用 AI Agent 會不會洩露公司機密？

使用 AI Agent 時的資料安全取決於以下因素：

商業模型 API（OpenAI、Anthropic、Google）：
- 這些平台通常承諾不會使用 API 呼叫的資料來訓練模型
- 但資料會經過這些公司的伺服器，需要信任他們的安全措施
- 建議：不要將高度機密的資料透過 API 傳送

Hermes Agent 本身：
- 開源軟體，程式碼公開可審計
- 可以在本地運行，資料不會離開你的電腦（除非呼叫外部 API）

降低風險的做法：
- 對敏感資料進行去識別化（移除姓名、帳號等）後再讓 Agent 處理
- 使用沙箱後端限制 Agent 的檔案存取範圍
- 定期審查 Agent 的操作日誌
- 如果公司有資安政策，請先與 IT 部門確認

---

### Q16：Agent 會不會執行危險操作，例如刪除重要檔案？

這正是 Harness 存在的理由之一。Hermes Agent 的安全機制包括：

- 沙箱後端：Agent 的檔案操作在受限制的沙箱環境中執行，不能存取沙箱外的檔案
- 權限控制：你可以明確設定 Agent 可以使用哪些工具、存取哪些目錄
- 操作審核：Agent 的所有操作都會被記錄，可以事後審查
- 人工確認：可以設定高風險操作需要人工確認後才執行

建議做法：
- 預設給予最小權限，只開放必要的工具和目錄
- 在正式環境使用前，先在測試環境中驗證 Agent 的行為
- 定期檢查 Agent 的操作日誌

---

### Q17：使用 AI Agent 有沒有法規遵循的問題？

在台灣使用 AI Agent 時，需注意以下法規面向：

- 個人資料保護法：如果 Agent 處理包含個人資料的內容，需確保符合個資法的要求
- 營業秘密法：不要將公司的營業秘密透過外部 API 傳送
- 著作權法：Agent 生成的內容可能涉及著作權議題，特別是用於商業用途時

建議：
- 了解公司是否有 AI 使用相關政策
- 處理敏感資料前與法務或合規部門確認
- 選擇有明確資料處理政策且符合法規的 AI 服務供應商

## 五、成本類

### Q18：使用 AI Agent 的 API 費用大約多少？

費用取決於使用的模型和使用量。以下是大致的參考價格（以 2025 年的價格為準，實際價格請查詢各平台官網）：

| 模型 | 輸入費用（每百萬 Token） | 輸出費用（每百萬 Token） | 適合場景 |
|------|--------------------------|--------------------------|----------|
| GPT-4o Mini | ~$0.15 USD | ~$0.60 USD | 日常簡單任務 |
| GPT-4o | ~$2.50 USD | ~$10 USD | 複雜推理和分析 |
| Claude Haiku | ~$0.25 USD | ~$1.25 USD | 快速回應、大量處理 |
| Claude Sonnet | ~$3 USD | ~$15 USD | 平衡品質與成本 |
| Gemini Flash | ~$0.075 USD | ~$0.30 USD | 高性價比任務 |
| Gemini Pro | ~$1.25 USD | ~$5 USD | 複雜任務 |

實際花費估算：
- 課堂練習（約 20–30 次 API 呼叫）：約 $0.5–2 USD（使用 GPT-4o Mini）
- 日常辦公使用（每天 30–50 次對話）：約 $1–5 USD/天（使用中等模型）
- 重度使用（大量文件處理）：可能達到 $10–30 USD/天

省錢技巧：
- 簡單任務使用較便宜的模型（如 GPT-4o Mini、Claude Haiku）
- 將長文件先摘要再傳給 Agent，減少 Token 用量
- 善用排程功能，避免重複查詢相同資訊
- Google Gemini 有免費額度，適合實驗和學習

---

### Q19：除了 API 費用，還有其他成本嗎？

可能的額外成本：

- 基礎設施：如果需要 24 小時運行 Agent（如排程任務），可能需要一台雲端伺服器（約 $5–20 USD/月）
- 通訊平台：Telegram Bot 免費；Slack 可能需要付費方案才能使用某些功能
- 學習時間：熟練使用 Agent 需要投入學習時間，這也是一種隱性成本

對大多數個人使用者來說，每月的總成本大約在 $5–30 USD（約 NT$160–960），取決於使用頻率和模型選擇。

---

### Q20：如何控制 API 費用不超支？

建議採取以下措施：

1. 設定預算上限：各大 AI 平台都提供使用量上限設定功能，建議設定每月預算
2. 監控使用量：定期查看各平台的使用量儀表板
3. 分層使用模型：簡單任務用便宜模型，複雜任務才用強大模型
4. 優化提示詞：精準的提示詞可以減少來回對話次數，降低 Token 消耗
5. 善用快取：Hermes Agent 的記憶系統可以避免重複處理相同的請求
6. 設定警示：在 AI 平台設定費用警示，達到閾值時通知
