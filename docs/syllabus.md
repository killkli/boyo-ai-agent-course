# 辦公室 AI Agent 實戰入門 — 課程大綱

## 基本資訊

- 課程名稱：辦公室 AI Agent 實戰入門
- 時數：6 小時（實體課程）
- 對象：在職人士、一般成人
- 先備知識：基本電腦操作能力，無程式設計經驗亦可
- 教學語言：中文

## 課程目標

完成本課程後，學員將能夠：
1. 理解 Model、Harness、Agent 三層架構及其關係
2. 區分「AI 模型」與「AI Agent」的本質差異
3. 理解 Harness 框架如何讓 AI 安全可控地執行任務
4. 安裝並操作 Hermes Agent 執行基本辦公任務
5. 規劃一個可在自身工作場景中落地的 Agent 應用方案

## 各堂摘要

### 第 1 堂：AI 生態系概覽
從 ChatGPT 到 Agent 的演進，建立三層架構（Model → Harness → Agent）的全貌理解。

### 第 2 堂：認識 AI 模型
語言模型的基礎原理、主要模型家族、能力邊界，以及不同模型執行同一任務的差異 Demo。

### 第 3 堂：Harness 控管框架
「模型提供智慧，Harness 提供控制」的核心概念。對比 Claude Code 的 QueryEngine 與 Hermes 的 AIAgent 兩種設計。

### 第 4 堂：Agent 解剖學
Agent 的組成要素（Model + Harness + Tools + Memory），工具系統設計、記憶機制、安全性考量。

### 第 5 堂：Hermes Agent 實作
安裝 Hermes Agent、完成第一個任務、啟用工具、觀察自學習迴圈。

### 第 6 堂：博幼基金會場景工作坊
分組挑選博幼基金會場景（課輔中心週報彙整、教學會議記錄、學童家長來信、課輔計畫進度監控），實作並 Demo 成果。

## 評量方式

- 課堂參與與討論（30%）
- 第 5 堂 Hands-on 實作完成度（30%）
- 第 6 堂工作坊分組成果發表（40%）
