# Agent Tutor — 辦公室 AI Agent 實戰入門

6 小時實體課程的規劃專案，教導在職人士理解 Model-Harness-Agent 三層架構，並實際操作 Hermes Agent 應用於辦公室場景。

## 課程架構

| 堂次 | 主題 | 時長 | 型態 |
|------|------|------|------|
| 1 | AI 生態系概覽 | 50min | 講授 + 討論 |
| 2 | 認識 AI 模型 | 50min | 講授 + Demo |
| 3 | Harness 控管框架 | 50min | 講授 + 程式碼導讀 |
| 4 | Agent 解剖學 | 50min | 講授 + Demo |
| 5 | Hermes Agent 實作 | 50min | Hands-on Lab |
| 6 | 辦公室場景工作坊 | 60min | 分組實作 + 發表 |

## 核心技術棧

- Hermes Agent — Nous Research 開源 AI Agent 框架（MIT 授權）
- Harness Paradigm — 模型提供智慧，Harness 提供控制
- Model-Agent-Harness 三層架構 — 本課程的核心知識框架
